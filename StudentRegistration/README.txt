STUDENT REGISTRATION FORM - C# WINDOWS FORMS

REQUIREMENTS
- Windows computer
- Visual Studio 2022
- .NET 8 SDK / .NET desktop development workload

OPEN THE PROJECT
1. Extract StudentRegistration.zip.
2. Open Visual Studio 2022.
3. Choose Open a project or solution.
4. Open the StudentRegistration folder.
5. Select StudentRegistration.csproj.
6. Wait for Visual Studio to load/restore the project.
7. Press F5 or click the green Start button.

USE THE FORM
1. Enter student name, email and a 10-digit phone number.
2. Select gender and course.
3. Select at least one hobby.
4. Choose date of birth.
5. Click Submit to validate and display the summary.
6. Click Clear to reset the form.

NOTE
The form controls and layout are created in Form1.cs in code.
There is no separate Form1.Designer.cs file in this version.
