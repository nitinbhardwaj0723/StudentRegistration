STUDENT REGISTRATION FORM - C# WINDOWS FORMS

REQUIREMENTS
- Visual Studio 2022
- .NET 8 SDK / .NET desktop development workload

USE THE FORM
1. Enter student name, email and a 10-digit phone number.
2. Select gender and course.
3. Select at least one hobby.
4. Choose date of birth.
5. Click Submit to validate and display the summary.
6. Click Clear to reset the form.
